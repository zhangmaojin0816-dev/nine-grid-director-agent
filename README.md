# 九格导演 Agent

一个面向 AI 视频创作者的分镜提示词工作台。输入一句创意、故事或剧本后，工具会补充人物心理、环境、动作、神态与镜头语言，并输出可以直接交给视频生成工具使用的整片提示词。

## 主要能力

- 生成 2–9 个可调分镜，并按目标总时长分配每镜秒数
- 支持故事／剧本、提示词规范和混合 Markdown、TXT、DOCX 文档
- 支持最多 15 张人物、场景、道具或风格参考图
- 适配 Seedance、Kling、Runway 和 Luma 的提示词表达
- 可单独重写某个镜头，其余分镜保持不变
- 按需调用图片模型生成线稿分镜，避免无谓消耗
- 整合输出美术风格、人物设定和完整分镜长提示词
- 支持 OpenAI、DeepSeek、通义千问、豆包、智谱、Kimi、OpenRouter、Groq及兼容接口

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
git clone <你的仓库地址>
cd nine-grid-director-agent
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：

```bash
npm test
npm run start
```

## API Key 与隐私

项目默认不内置、不持久化任何 API Key。用户在界面中填写 Key 后，浏览器只在当前会话中保存，并通过本项目的服务端路由转发给所选模型供应商。

公开部署前请注意：部署服务器仍会处理用户提交的 Key。建议让用户自行部署，或者为公开服务增加后端密钥托管、用户鉴权、限流和日志脱敏。不要把真实 Key 写进源码、环境示例、截图或提交历史。

## 文档与图片限制

- 文档：DOCX、TXT、MD，单文件最大 5 MB，最多导入 200,000 字符
- 单次生成：故事和规范合计最多 20,000 字符
- 图片：PNG、JPEG、WebP，单张最大 3 MB，最多 15 张

## 验证

```bash
npm test
```

测试覆盖分镜时长、单镜头重写、模型接口、文档识别与长 Markdown 导入等核心流程。

## 克隆发布建议

1. Fork 或使用 GitHub 的 `Use this template` 克隆仓库。
2. 在全新目录执行 `npm install && npm test`。
3. 确认克隆版本不包含原作者 API Key、会话和本机路径。
4. 根据目标托管平台配置支持服务端 API Route 的 Node 或兼容运行环境。
5. 用全新实例完成“输入故事—生成分镜—重写单镜—复制整片提示词—按需生成线稿”的黑盒验收。
